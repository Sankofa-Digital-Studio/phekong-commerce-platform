# Contributing

> **Sankofa Digital Proprietary and Confidential — Not for Distribution**

## Branches
- `main`: protected production branch
- `feature/<issue>-short-name`
- `fix/<issue>-short-name`
- `docs/<issue>-short-name`
- `test/<issue>-short-name`
- `hotfix/<issue>-short-name`

## Workflow
1. Work from an assigned GitHub issue.
2. Create a branch from the latest `main`.
3. Commit small, reviewable changes.
4. Run lint, type-check, tests and build.
5. Open a pull request using the template.
6. Attach screenshots or test evidence.
7. Do not merge your own work.
8. Direct commits to `main` are prohibited.

## Commit convention
`type(scope): description`

Types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `security`.
